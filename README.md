# FitPulse - Smart Fitness Watch Landing Page

## 📌 Overview
A fully responsive landing page for a Smart Fitness Watch built using pure HTML, CSS, and Vanilla JavaScript — no frameworks or libraries used.

## 🔗 Live Demo
https://elisettisanjana.github.io/fitpulse-Landing-Page

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript

## 📄 Sections
- Header with logo & navigation
- Hero section with product image & CTA
- Key Features (4 features)
- Pricing Plans (Basic & Pro)
- Testimonials (accordion)
- Email signup with validation
- Footer

## ✨ Features
- Mobile-first responsive design
- Hamburger menu toggle
- Accordion testimonials
- Email form validation
- Hover states & transitions
